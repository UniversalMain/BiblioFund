Көшірмеден қалпына келтіру

Көшірмедегі барлық оқу жылдарының әдеби кітаптары мен есептері ағымдағы деректерді толық алмастырады.

Алмастыру алдында ағымдағы нұсқа осы браузерде бөлек сақталады. Оны «Сақтау туралы» терезесінен жүктеп алуға болады.

Сақтау туралы

Әдеби кітаптар, маусымдық есептер және таңдалған оқу жылы әр өзгерістен кейін осы браузерге автоматты түрде сақталады. Бетті қайта ашқанда деректер қалпына келеді.

Браузер деректерін тазалау, жасырын режим, HTML файлын көшіру немесе атын өзгерту сақталған деректерге қолжетімділікті жоғалтуы мүмкін. Резервтік көшірмені жүйелі түрде жүктеп алыңыз.

Басқа компьютерге көшу үшін JSON көшірмесін жүктеп, сол компьютерде қалпына келтіріңіз. CSV — тек кесте экспорты; толық қалпына келтіру үшін JSON көшірмесін пайдаланыңыз.

Бұлттық базаға қосылу үшін жоғарғы жақтағы ☁ белгішесін басыңыз. Қосылған соң каталог автоматты түрде синхрондалады. Интернет болмаған жағдайда соңғы жергілікті көшірме көрсетіледі.
